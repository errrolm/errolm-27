# errolm · 2026

This is the 2026 iteration of [errolm.vercel.app](https://errolm.vercel.app) — my personal site built with [Astro](https://astro.build), Tailwind CSS, and a sprinkle of custom MDX enhancements.

It’s a minimal, dark-themed, fast, no-bloat site meant to do exactly three things:
- showcase projects,
- publish thoughts,
- and stay true to my style.

## 🔧 Stack

- **Astro** — static site generator
- **Tailwind CSS** — utility-first styling
- **MDX** — write blog posts in Markdown + JSX
- **Custom components** — handcrafted layout, routing, and typography
- **SEO** — full Open Graph, Twitter meta, and analytics via Umami
