I built an anonymous chat site called **Whisfer**, like *whisper*.

This wasn’t a serious project. I got bored and wanted to make something quick and weird. You can try it out at [**whisfer**](https://whisfer.vercel.app).

Messages disappear after **48 hours**, and there are **reactions** too. More stuff is probably coming, like **spaces**, which are basically group chats people can create and join.

_"Sometimes the best ideas are the ones you don't think too hard about."_

## The Stack I'm Using

Built with:

- **Vite** + **React (JSX)**
- **Tailwind CSS** for styling
- **Firebase** for backend + data
- **Vercel** for hosting
